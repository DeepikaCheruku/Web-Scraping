# Web Scraping – Largest Companies in the United States

## 📌 Project Overview

This project demonstrates how to scrape data from a real website using Python.

The data is collected from Wikipedia's **List of largest companies in the United States by revenue** page. The project extracts the table containing company information and converts it into a Pandas DataFrame.

## 🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

## 🔍 What This Project Covers

- Sending an HTTP request to a website using `requests`
- Using `BeautifulSoup` to parse HTML
- Finding a specific HTML table
- Extracting table headers
- Extracting rows and columns from the table
- Creating a Pandas DataFrame
- Exporting the scraped data to a CSV file

## 📂 Files

- `Scraping Data from a Real Website.ipynb` – Jupyter Notebook containing the complete web scraping process.
